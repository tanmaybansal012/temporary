Netlist Format Documentation

The Netlist file (.net) defines the architecture of your digital logic circuit. It uses a simple, human-readable syntax to declare inputs, logic gates, sequential elements, and outputs.

1. Global Directives

INPUT

Declares the primary input wires for the circuit. You can declare multiple inputs on a single line separated by spaces.

INPUT A B CLK

OUTPUT

Declares which wires should be tracked as the final outputs of the circuit.

OUTPUT Q Q_BAR

Comments

Any blank line or line starting with a # symbol is ignored.

# This is a comment explaining the circuit

2. The GATE Directive

The GATE directive is the core of the netlist. It instantiates a logic component and wires it into the circuit.

GATE <Gate_Name> <Gate_Type> <Input_Wire_1> [Input_Wire_N...] [-> <Output_Wire_1>...]
Parameter Description
<Gate_Name> A unique identifier for this component (e.g., AND1, FF_A). By default, the output wire of this gate assumes this exact name.
<Gate_Type> The specific type of logic gate or flip-flop (see Reference below).
<Input_Wire_N> The names of the wires feeding into this component. Order matters for components like Muxes or Flip-Flops!
-> <Output_Wire> (Optional) Use the -> operator to explicitly name the output wires of the component. Required for elements with multiple outputs (like Q and Q_bar).

3. Component Reference

Combinational Logic Comb

Keyword Inputs Required Description
NOT 1 Logical Inverter.
AND, OR, NAND, NOR, XOR, XNOR 2 or more Standard logic gates. You can supply as many inputs as you want (e.g., a 4-input AND gate).
MUX2 3 (A, B, SEL) 2-to-1 Multiplexer.
MUX4 6 (D0..D3, S0, S1) 4-to-1 Multiplexer.
DEC2X4 3 (A0, A1, EN) 2-to-4 Decoder. Outputs 4 distinct wires.
DEC3X8 4 (A0, A1, A2, EN) 3-to-8 Decoder. Outputs 8 distinct wires.

Sequential Logic Seq

Keyword Inputs Required Description
DFF 2 (D, CLK) D Flip-Flop (Edge-Triggered).
JKFF 3 (J, K, CLK) JK Flip-Flop (Edge-Triggered).
TFF 2 (T, CLK) T (Toggle) Flip-Flop (Edge-Triggered).
SRLATCH 2 or 3 (S, R, [EN]) Set-Reset Latch. The Enable (EN) pin is optional.
DLATCH 1 or 2 (D, [EN]) Transparent D-Latch. The Enable (EN) pin is optional.

4. Complete Example

Here is an example of a simple circuit featuring a D-Flip Flop and an XOR gate (a basic toggle circuit with enable).

# Declare Inputs
INPUT EN CLK

# Combinational Logic (XOR gate)
GATE TOGGLE_LOGIC XOR EN FF1_Q

# Sequential Logic (D Flip-Flop)
# Note how we use '->' to explicitly name the Q and Q_bar outputs
GATE FF1 DFF TOGGLE_LOGIC CLK -> FF1_Q FF1_QBAR

# Declare Outputs
OUTPUT FF1_Q
